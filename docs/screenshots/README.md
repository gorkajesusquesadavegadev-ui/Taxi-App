## Cómo capturar la vista móvil

1. Abre la app en Chrome → `F12` (DevTools) → icono de móvil (Ctrl+Shift+M).
2. Elige un dispositivo (p. ej. iPhone 12 Pro, 390×844).
3. En el menú `⋮` de la barra del dispositivo → **Capture screenshot**.
4. Renombra el PNG según la tabla y déjalo en esta carpeta.

Recomendado: mismo dispositivo en todas para que se vean uniformes.
